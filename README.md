# deep-time-demos

Code for the computer demonstrations shown in Deep Time Research Institute videos. Each folder is self-contained: the
script, its results, and a README with the seed and how to reproduce the results byte for byte.

| folder | video | what it shows |
|---|---|---|
| [`ep04-coincidence/`](ep04-coincidence/) | Why Almost Every Ancient "Alignment" Is a Coincidence | random dots make straight-line "alignments"; how many lines chance produces; how often noise looks "significant" |

The demonstrations are illustrations of a method, not research results about any real place. MIT licence (`LICENSE`).
